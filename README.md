# 🎣 Reel Rush

An endless vertical reel-'em-up for the family. Hook a fish deep in the ocean
and **reel it up to the boat** — dodging sharks and sea mines on the way, and
staying ahead of the deep shark rising from below. Land it, and the next cast
drops even deeper for an even bigger fish.

**Play it:** https://rvenning.github.io/reel-rush/

## How to play

- **Hold** anywhere (or Space / ↑) to reel your catch up. Let go and the fish
  sinks — heavy fish sink fast, so keep working.
- **Slide** left/right (or ← / →) to steer around 🦈 sharks and 💣 sea mines.
- Grab ⚪ pearls for bonus points and power-ups: 🫧 shield, 🪝 power reel, ❄️ freeze.
- Reach the boat to **land the catch** — bigger fish are worth far more, and a
  chain of catches without a hit multiplies your score.
- Three lives. The deep shark below is always rising — don't dawdle.

## Features

- Six fish from Minnow to Whale, unlocked by fishing deeper.
- Five depth zones from the Sunlit Shallows to the Abyss.
- Six unlockable lures (cosmetic), earned by lifetime fish landed.
- Name-pick family profiles with PINs, a shared leaderboard, and cross-device
  sync — every angler on every phone and tablet in one place.
- Installable (PWA) and fully playable offline.

## Built on gamekit

Profiles, storage + family sync, the sound engine, screens/modals, canvas juice
and PWA install all come from the shared **gamekit** library, vendored into
`lib/`. To pull a newer gamekit in:

```
node "D:\OneDrive\Documents\Claude Code\gamekit\tools\sync-to-game.js" "D:\OneDrive\Documents\Claude Code\reel-rush"
```

Never edit `lib/` directly — it's a vendored copy and the next sync overwrites it.

## PWA files

- `manifest.json` — app name, colours, icons
- `sw.js` — network-first service worker (bump `CACHE` on any shell change)
- `icons/` — generated by `node tools/make-icons.js`

## Local development

No build step. Serve the folder and open it:

```
npx http-server "D:\OneDrive\Documents\Claude Code\reel-rush" -p 8105 -c-1
```

Run the balance/data tests with `npm test` (needs Node; no extra deps).

## Storage

- **localStorage** prefix `rr_` for profiles, progress and settings.
- **Firestore** collection `reelrush` in the shared `wordvoyage-e5a5c` project
  for family sync. The client API key in `js/firebase-config.js` is public by
  design — it's restricted to the Cloud Firestore API and the games' origins.
